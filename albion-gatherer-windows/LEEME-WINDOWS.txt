Albion Gatherer — versión Windows (CÓDIGO FUENTE)
=================================================

Esta carpeta es el CÓDIGO del bot para Windows. El usuario final NO necesita
nada de aquí: descarga el programa ya listo (AlbionGatherer.exe) desde la
sección "Releases" del repositorio y lo abre con doble clic. Toda la
configuración se hace dentro del propio programa.

Es el mismo bot inteligente y en español que la versión de Linux, con la
interfaz rediseñada (estilo overlay oscuro con acento oro) y adaptado a
Windows: la configuración se guarda en %APPDATA%\AlbionGatherer\.


CÓMO RECONSTRUIR EL .EXE (solo para desarrollo)
-----------------------------------------------
Con Python 3.10+ instalado (marcando "Add python.exe to PATH"):

    python -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt pyinstaller
    .venv\Scripts\pyinstaller --onefile --windowed --name AlbionGatherer ^
        --collect-all customtkinter app.py

El resultado queda en  dist\AlbionGatherer.exe  (un único archivo).


ARCHIVOS
--------
- app.py               Interfaz (customtkinter, tema oscuro + oro)
- engine.py            Máquina de estados con la lógica inteligente (hilo)
- vision.py            Captura de pantalla + coincidencia de plantillas (mss + OpenCV)
- input_controller.py  Control humanizado del ratón (pynput)
- recorder.py          Grabador de puntos y plantillas por atajos F7/F8
- config.py            Configuración (se guarda en %APPDATA%\AlbionGatherer\)
- requirements.txt     Dependencias de Python
